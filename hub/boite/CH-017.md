## Interface `changerPartie` et diff proposé (à appliquer par l'intégrateur)
`chantiers/CH-017/adaptateur-changer-partie.patch` (40 lignes, `git apply` propre) : `src/adapter-page.js` + `src/bridge.js` (ajout à la liste des actions permises).
- Appel : `changerPartie({part})`. Refus sans rien cliquer : `{ok:false, raison}` (`partie-invalide`, `occupe`, `libelle-illisible`, `partie-absente`). Déjà sur la partie : `{ok:true, deja:true}`. Sinon : réponse **avant** le clic sur le lien `p=N` (le clic recharge peut-être la page), `{ok:true, mode:'lien', de:{part,cut}, vers, demandeA}`.
- La réponse n'est qu'un **accusé de demande**. La **preuve** est la partie demandée lue par le service worker (« Cut N of part P », rails présents) dans la borne de 60 s ; après un rechargement, l'onglet est ré-équipé. `ping` rend `capacites:['changerPartie']` : sans elle, le service worker n'envoie rien et la file s'arrête sur « commande-absente » (c'est le cas du dépôt tant que le diff n'est pas appliqué).
- Pour allumer : appliquer le diff, `file.actif:true`, version. **Pas avant le relevé de l'opérateur** sur un vrai changement de partie (le sélecteur `p=N` est SUPPOSÉ).

## Constats
1. **La relecture ne part pas quand ESV affiche une autre partie** (`lotCloRefus`), or ESV charge la partie suivante au dernier cut (terrain du 30/09). Pour tenir D-261, la file ramène ESV sur la partie du lot (même commande) et relance la relecture, une fois ; sinon elle note le motif et continue. ÉTABLI dans le code ; essai vm vert.
2. **Lot en `ERROR` au dernier cut d'une partie (maquette)** : le dernier cut à valider était « skipped » ; Ctrl+Entrée sur un cut déjà compté « traité » ne fait pas bouger le compteur « N on M treated », le lot finit en `ERROR`. ÉTABLI sur la maquette ; PROBABLE sur ESV si « traité = validé ou passé ». Préexistant (lot, pas file) ; la file s'arrête désormais dessus (« refus-lot ») au lieu d'attendre.
3. Sur la maquette, la relecture de chaque partie s'arrête en erreur (cuts hors du scénario de la maquette) : la file continue en notant le motif (défaut D-247). Limite de la maquette.
4. `tests/esv-maquette/adaptateur.test.cjs`, « précision des nœuds », lisait les nœuds avant leur chargement (6 échecs sur 6 sur le tronc quand il suit « retour à une coupe » seul) : attente du chargement ajoutée ; le fichier entier passe 3 fois sur 3.
5. Lancé en parallèle des autres fichiers, l'essai de la file (deux Chromium, lots réels) faisait manquer ses délais à « Connexion T21 » (1 échec dans la suite, 0 sans lui, 0 sur le tronc) : `essais.cjs` le lance désormais après les autres, seul.

## SUPPOSÉ, à confirmer par l'opérateur
« Partie 1 sur N » = la partie affichée, puis les N−1 suivantes du sélecteur ; refus en clair si le sélecteur en offre moins. Seuils de l'alerte (différés hors passe > 2 × la médiane des parties précédentes, corrigés > 5 %, refus ≥ 1 ; les refus comptés sont ceux de la relecture). Une pause du lot ne fait pas avancer la file (elle attend l'opérateur). Tableau des motifs (D-248) et exception « écriture incertaine ».
