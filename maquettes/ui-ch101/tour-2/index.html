À savoir

  • Police. Les trois propositions sont affichées avec la police de l’appareil qui ouvre cette page (Segoe UI sous Windows, San Francisco sous macOS, Roboto sous Android). Le panneau d’aujourd’hui est une photographie : sa police est IBM Plex.
  • Thème. Dans l’extension, le clair ou le sombre suivrait le réglage du système ; ici les deux boutons servent à comparer.
  • Rien n’est installé. Ce sont des maquettes ; l’extension n’a pas changé.

Libellés à remplacer, si tu le veux

  • « Utilisé par Ariane — ESV » (coupé dans le panneau actuel) : proposer « ESV connecté ».
  • « …ou le passer » dans le message du rail non résolu : le bouton pour passer est masqué ; proposer de retirer ces mots.
  • « Relecture 12 sur 85 » sous le titre « Relecture » : proposer « 12 sur 85, 3 corrigés · cut 4801 ».

Les autres écrans

  • 1. Écho, Constellation, Aurore et les réglages gardent leur place et reçoivent les mêmes finitions.
  • 2. Chaque écran devient une ou deux cartes ; les réglages prennent la forme des réglages de Chrome (une ligne, un interrupteur).
  • 3. Chaque écran devient un titre et une liste de lignes ; l’Aurore et la Constellation sont déjà des listes.
