Détour

Logique. Ce qui vous demande quelque chose est détouré et posé devant vous, avec son ombre ; tout ce qui se passe sans vous reste à plat, dans le fond.

D’où ça vient. remove.bg : le parcours déposer → image assombrie pendant le calcul → figure seule sur un damier ; les réglages « Add Shadow » et « Blur background » ; le bouton de sortie qui ne s’allume qu’à la fin ; la bascule avant / après. backgrounds.supply : dans chaque collection, la netteté dit l’accès (net = à vous, flou + « Locked » = pas encore). Le vocabulaire des outils d’image : la sélection en « fourmis » qui avance, les calques.

Ce que ça veut dire ici. Matière pleine = cuts traités ; damier = pas encore traité (rien ici). Trou dans la matière, où l’on revoit le damier = différé : Ariane n’a rien posé là. Petite encoche = vert à examiner. Sélection en fourmis = le cut qu’Ariane travaille ; les fourmis marchent quand elle travaille, s’arrêtent en pause. Carte détourée avec ombre et filet noir = vous êtes attendu (pause, arrêt, incident, fin, alerte, examen) ; pendant que le lot tourne seul, il n’y a aucune carte détourée. Les parties d’une file sont des calques : faits, courant, vides.

Mouvement. À chaque changement d’état, la carte qui vous attend se détoure : son contour se trace de gauche à droite en 0,4 s, puis l’ombre se pose (0,6 s au total). Les fourmis avancent d’un pas toutes les 0,9 s tant que le lot tourne. Un nouveau différé s’ouvre en trou en 0,45 s. Mouvement réduit : fourmis immobiles, cartes posées sans tracé.
