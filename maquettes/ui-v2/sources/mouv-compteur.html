Le compteur

Logique. Un compteur mécanique est la seule signalétique : ses tambours roulent d’un cran à chaque cut, un cliquet tombe en pause, une barre les bloque à l’arrêt, un seul tambour hésite quand Ariane attend l’opérateur, et tous font un tour complet quand le lot est fini.

D’où ça vient. 60fps.design : Number Flip with Reflection (le chiffre neuf glisse, les autres ne bougent pas), Circle Wallet Claim Balance et Revolut Number of Transactions (compteur qui roule puis se pose), Tactile Button (le bouton qui s’enfonce sur sa tranche, repris pour toutes les actions). beui.dev, Number Animation (code lu) : chaque chiffre est une colonne 0–9 repérée par son rang depuis la droite, si bien qu’un chiffre qui change roule au lieu de réapparaître ; le décalage entre chiffres n’est joué qu’une fois. Guide de beui.dev : « linear for progress », ressort court pour un objet qui se pose.

Ce que ça veut dire ici. Le cran qui tombe toutes les secondes sur le tambour des unités : le lot tourne. Plus rien ne bouge et un cliquet est posé contre les tambours, avec le mot « en pause » : la prochaine avance attend. Une barre rouge marquée « arrêté » en travers : le lot s’est arrêté. Seul le tambour du cut oscille, sans avancer, avec le mot « à vous » : Ariane a besoin de l’opérateur. Le tambour du cut tourne sans fin, lentement : relecture d’une partie, rien n’est posé. Un cadre en pointillé « total inconnu » : le total n’est pas deviné. Aucune couleur ne porte seule un sens : l’ocre accompagne « à vous », le rouge « arrêté ». En mouvement réduit, les tambours se posent sans rouler ; le cliquet, la barre et les mots restent.
