# Référence : wedoflow.com (boutique de gabarits Webflow)

## Ce que j'ai ouvert exactement (Chromium, navigation ordinaire, 29/10)
- Accueil (2 984 px) : bandeau orange « 95% OFF », titre centré blanc sur noir, filtres « Categories / Tags », grille de gabarits (nom, prix, catégorie, « Subscribe to Download »). ÉTABLI.
- Catégories par étiquette : « Blog » (/tags/blog, 12 692 px), « Design » (/tags/design). Page « Insights » (blog, 25 404 px). ÉTABLI.
- Trois fiches de gabarits choisies pour leur nom typographique : « Swiss », « Boldest », « Black Zero » ; puis leurs aperçus en ligne (« Preview in Browser ») : az-swiss, az-boldest, az-black-zero. ÉTABLI.
- Polices mesurées : Swiss = Space Grotesk 600 à 65-70 px + Inter ; Boldest = Manrope 800 jusqu'à 210 px + Open Sans ; Black Zero = Manrope 600 62 px + Inter sur fond noir. ÉTABLI.

## Ce que j'y ai vu (structure, grille, typographie)
1. **Fiche de gabarit** : colonne de droite fixe (nom, catégorie, description, prix, deux boutons « Browser / Designer »), à gauche une **liste numérotée des pages** (« 1. Home 2. Features … 18. Change Log »). L'index numéroté est la seule idée éditoriale franche. ÉTABLI.
2. **Boldest** : chiffres énormes avec leur libellé collé à droite en petit (« 35+ minutes per session », « 5.0 review average », « $0.00 everything is FREE ») ; le nombre et son unité forment une seule ligne lisible. ÉTABLI.
3. **Swiss** : malgré son nom, pas de grille suisse : cartes à coins arrondis, dégradés violets, photos de cartes bancaires. Les pages de démonstration présentent chaque écran avec une pastille « New ». ÉTABLI.
4. Black Zero : vitrine sombre d'application, maquettes de téléphone, dégradés. ÉTABLI.
5. Les gabarits suivent tous la même structure (héros centré, logos, trois colonnes de bénéfices, prix, FAQ) : c'est la grammaire de page « SaaS » standard. ÉTABLI.

## Ce que j'en retiens pour Ariane
- **Le nombre géant + son unité en petit sur la même ligne** (Boldest) : « 112 traités » ou « 128 restent », pour la lecture à trois mètres.
- **L'index numéroté** de la fiche (1., 2., 3.) pour la liste de ce qui reste et pour les parties d'une file.
- Contre-exemple utile : Swiss montre qu'un nom typographique ne suffit pas ; la grille doit être réelle (colonnes, alignements) et non décorative.

## Ce que j'écarte et pourquoi
- Dégradés violet-bleu, pastilles « New », maquettes de téléphone, bandeau promotionnel orange : exactement le registre que l'opérateur rejette (« vibe codé »).
- Les héros centrés : un panneau étroit se lit de haut en bas, aligné à gauche.

## Erreurs d'accès
- Aucune (toutes les pages en 200).
