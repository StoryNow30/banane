# Maquette « Vivant » (vivant.html), intégrateur

**Logique en une phrase.** La lumière chaude ne paraît que là où Ariane agit : sur le mot d'état quand le lot tourne et sur la seule action qui fait avancer ; si rien ne brille, rien ne tourne.

**Références et ce qui en est pris.** heydamir (lu, ÉTABLI) : fond anthracite chaud, appareils à double cadre arrondi, bouton crème qui rayonne, mot clé en dégradé pêche. ThinkingOrbs (README et code lus) et libraries.dev Thinking orbs (page jouée) : orbe en points dans une pastille, une forme par activité, libellé qui scintille pendant le travail, image fixe en mouvement réduit.

**Sens des signes.** Lumière chaude = Ariane agit. Orbe : orbites = pose ; cercle qui respire = pause ; bandes qui se remettent en ordre = relecture ; onde dans des anneaux = Écho ; globe qui balaie = cherche ESV ; globe plein = lot posé. Frise : point plein = posé ; point creux = différé ; losange bleu froid = vert à examiner ; points cerclés pâles = total inconnu. Bleu froid + losange = « à examiner », jamais autre chose.

**Partition de mouvement.** Changement d'activité → l'ancienne forme se replie et la nouvelle se déploie, 0,6 s, sortie cubique → réduit : la forme change d'un coup. Pendant le travail → l'orbe tourne, le libellé scintille (phase calée sur l'horloge pour survivre au rendu périodique) → réduit : immobile, libellé plein. Valeur qui change → le chiffre monte à sa place, 0,42 s → réduit : rien. Changement d'état → les blocs arrivent l'un après l'autre (décalage 40 ms, 0,48 s) → réduit : rien.

**Pourquoi sans voie ni nuage.** L'orbe est une forme abstraite d'activité (orbites, onde, bandes), pas le relevé ; seule la vue Examiner montre la coupe, comme contenu.

**Autocritique.** Le dégradé pêche peut faire « page d'agence » ; il est limité à un mot et à un seul état. Les vignettes de coupe de la liste sont petites et peu lisibles.

**Vérificateur.** 0 écart, 0 erreur de console ; contraste minimal 5,42:1.
