# Maquette « Mosaïque » (mosaique.html), intégrateur

**Logique en une phrase.** Le lot est une image qui se forme : une tuile par cut, floue tant qu'elle n'est pas faite, nette quand Ariane l'a posée.

**Références et ce qui en est pris.** libraries.dev Image (paquet lu ; page non chargée, délai dépassé) : mosaïque de gros pixels qui se résout en image nette. inspora (grille vue) : images en trame, filtres en pavés gris. backgrounds.supply (lu) : collection ASCII et trames. 60fps : compteur qui s'anime.

**Sens des signes.** Tuile floue = à faire. Tuile nette = posé. Gros pixels encadrés = différé. Coin corail et losange = vert à examiner. Rangée tiretée en bas = total inconnu. L'image est abstraite (deux ondes qui interfèrent) : elle ne représente rien du relevé.

**Partition de mouvement.** Cut posé → la tuile passe de 1 à 2, 4 puis 8 pixels de côté en 0,5 s environ → réduit : nette d'un coup. Tuile en cours → respire faiblement → réduit : fixe. Examen → la tuile agrandie se résout → réduit : nette.

**Pourquoi sans voie ni nuage.** Première version : l'image figurait une voie ; remplacée par une image abstraite après l'avertissement de l'intégrateur.

**Autocritique.** La grille de 16 colonnes est dense à 360 px ; la police Array, très marquée, est réservée aux nombres.

**Vérificateur.** 0 écart, 0 erreur ; contraste minimal 4,68:1.
