# Maquette « Bassin » (bassin.html), intégrateur

**Logique en une phrase.** Une surface d'eau qui vit avec le lot : chaque cut posé fait une onde, ce qui reste flotte à la surface jusqu'à ce qu'on le regarde.

**Références et ce qui en est pris.** KoiPond (README et code Swift/Metal lus) : surface vivante, nénuphars qui dérivent, carpes qui glissent, toucher qui fait répondre l'eau, bassin ⇄ piscine en une seconde environ. inspora (grille vue) : bleus d'eau, aquarelle. 60fps (lu) : chaque geste reçoit une réponse.

**Sens des signes.** Onde = un cut vient d'être posé. Nénuphar vert = différé. Carpe orange = vert à examiner ; on touche l'un ou l'autre pour l'examiner. Eau calme = rien ne tourne. Piscine (carreaux) = Écho, Ariane regarde.

**Partition de mouvement.** Cut posé → une onde double s'élargit et s'efface en 2 s environ → réduit : aucune onde, compteurs écrits. Différés → dérive très lente → réduit : immobiles. Verts à examiner → la carpe tourne sur place → réduit : immobile. Orbite ⇄ Écho → fondu bassin/piscine d'environ 1 s → réduit : bascule nette. Toucher → onde au point touché.

**Pourquoi sans voie ni nuage.** Une surface d'eau ; aucune figure du relevé.

**Autocritique.** Métaphore douce, peut sembler ludique pour un outil de production ; les carpes et nénuphars demandent la légende la première fois.

**Vérificateur.** 0 écart, 0 erreur ; contraste minimal 5,17:1.
