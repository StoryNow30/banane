# Maquette « Faisceau » (faisceau.html), intégrateur

**Logique en une phrase.** Un faisceau de lumière fait le tour de la carte du lot tant qu'Ariane pose ; il se fige en pause et disparaît quand rien ne tourne : on voit de loin si le lot vit.

**Références et ce qui en est pris.** libraries.dev Border beam (page et code du paquet lus) : lueur qui court sur la bordure. SwiftPieces (README, pièces Liquid Glass) : cartes en verre sur un fond. backgrounds.supply (lu) : fond profond qui respire, barre de navigation en verre. beUI (lu) : Timeline qu'on fait glisser, Animated Alert qui se déplie.

**Sens des signes.** Faisceau qui tourne = le lot tourne ; faisceau figé = pause ; pas de faisceau = rien ne tourne. ○ = différé ; ◆ vert d'eau = vert à examiner. Trait tireté devant « ESV » = non relié. La frise aligne les cuts remarquables ; toucher un jalon ouvre l'examen.

**Partition de mouvement.** En cours → le faisceau fait un tour en 3,2 s, linéaire, phase calée sur l'horloge → réduit : faisceau absent, le mot « le faisceau tourne » reste écrit. Pause → faisceau arrêté à 200° → réduit : idem. Alerte → se déplie en 0,45 s avec un léger dépassement → réduit : apparaît. Fond → trois nappes dérivent en 9 s → réduit : fond fixe. Valeurs et changements d'état : comme Vivant.

**Pourquoi sans voie ni nuage.** Lumière sur verre ; aucune figure du relevé.

**Autocritique.** Le verre sur fond flou est un motif répandu ; il tient ici parce que le faisceau porte un sens précis. Le contraste est mesuré sur le fond de base, pas sur les nappes (limite du vérificateur).

**Vérificateur.** 0 écart, 0 erreur ; contraste minimal 6,33:1.
