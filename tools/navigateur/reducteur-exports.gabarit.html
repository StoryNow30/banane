Ariane — réducteur d'exports

Rend un export assez léger pour être envoyé. Rien n'est envoyé sur Internet : tout se passe dans ce navigateur, sur ton ordinateur. Rien à installer.

  1. Un dossier à la fois : un lot Orbite ou une relecture Écho.
  2. Glisse ici tous les fichiers .json du dossier (sélectionne-les tous avec Ctrl+A dans l'Explorateur), ou clique.
  3. Clique sur « Réduire », attends la fin (quelques minutes par Go), puis télécharge les fichiers proposés.
  4. Recommence pour chaque dossier, puis dépose tous les fichiers téléchargés dans la conversation.
