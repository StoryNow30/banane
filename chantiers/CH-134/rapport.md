- **Vue fil** (`src/signal-rendu.js`, `src/ui5.js`, section CH-134 de la feuille) : dans Orbite, lot ouvert ou fini, un bouton d'icône dans la ligne d'état (`sg:vue-lot`, `aria-label` « Vue fil » / « Vue instrument », `aria-pressed`). Il n'offre pas la vue fil : la vue réduite ne porte pas les derniers cuts (`fil: []`), il n'aurait qu'un fil vide ; le bouton est retiré par `filtrer` (`sg:vue-lot` hors de `NAVIGATION`). `telecommande/telephone.html` inchangé.
