# CH-095 : le faux ESV reproduit deux pannes réelles de Potree

**Exécutant :** agent. **Branche :** `chantier/CH-095` partie de `claude/50-test17`. **Coût prévu :** un chantier de maquette, aucun code livré dans l'extension.

## But
La maquette (`tests/esv-maquette/`) ne reproduit pas les pannes réelles de Potree ; cinq versions du préchauffage ont été corrigées par le terrain. À la fin, elle sait jouer, à la demande d'un essai : (1) un nœud dont le chargement échoue (réponse 5xx) et que Potree garde `loading` avec son compteur `numNodesLoading` non rendu (comportement décrit par CH-062 ; à relire dans le Potree de la maquette, et à dire tel quel si la maquette se comporte autrement) ; (2) une boîte de coupe qui contient plus de `hierarchiesMax` (8) pages de hiérarchie non lues.

## Ce qui est livré
1. Les deux pannes dans la maquette, déclenchées par un paramètre d'essai (éteintes par défaut : les essais existants ne changent pas).
2. Des essais navigateur (`tests/esv-maquette/ch095-*.test.cjs`) qui prouvent, sur le code du tronc (CH-089, CH-090, corrections de CH-092) : après un 502 sur un de nos chargements, le préchauffage se met en pause puis REPART et charge (pas de blocage muet) ; avec plus de 8 pages non lues, l'opération finit et la suivante est servie ; la capture de la coupe suivante n'est jamais retardée par un nœud bloqué à nous.
3. Si un de ces essais est rouge sur le tronc : c'est un défaut, tu le rapportes avec le chemin exact, sans corriger `src/` (l'intégrateur corrige).
4. `chantiers/CH-095/rapport.md` (une demi-page) : ce que la maquette reproduit, ce qu'elle ne peut pas reproduire, ce qui reste à relever sur le terrain.

## Interdits
- La liste de `CLAUDE.md`, en entier. Tu ne touches jamais toi-même `src/engine.js`, `src/adapter-page.js`, `src/geometry*.js`, `src/gcv2*.js`, `src/lot-decision.js`, l'écriture dans ESV, `manifest.json`, la version, le paquet, ni le tronc : si un de ces fichiers doit changer, tu livres un fichier `.patch` dans `chantiers/CH-095/` et l'intégrateur l'applique.
- Jamais de SKIP, jamais un cut non résolu validé. Aucun nom d'opérateur, code projet, adresse, UUID ni nom de modèle d'IA dans un fichier ou un commit. Aucune donnée terrain dans ce dépôt.
- Ne rapporter que du mesuré, qualifié ÉTABLI / PROBABLE / SUPPOSÉ.
