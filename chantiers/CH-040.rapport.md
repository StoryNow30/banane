## Cause (ÉTABLI, code et journal)
- `lotsACorriger` (`background.js`) prenait les lots du **bilan de la file courante**.
- La file relancée sur la partie 1 seule (lot `901a1a0e`) avait remplacé la file précédente (partie 0, lot `67467121` ; puis partie 1, lot `6768c769`, arrêté sur une erreur). La liste n'a donc porté que 15 cuts, tous de la partie 1.

## Correctif
- **`couverture`**, dans `src/correction-liste.js` (pur, version `correction-couverture-1`). Elle prend tous les lots du journal, c'est-à-dire la session depuis le dernier vidage, avec un plafond de 16 lots, les plus récents. Le lot ouvert est exclu.
- **Lot repris** (décision de l'intégrateur du 02/11) : un lot couvert par une Aurore à la fin `liste-finie` est exclu.
- **Toute autre fin** (`operateur`, c'est-à-dire « Terminer » à la main, puis `sw-redemarre`, `echo-ferme`) : le lot reste. Seuls ses cuts corrigés ou validés sont retirés. Un cut « à faire », « en cours » ou « vu » reste proposé.
- **Ordre** : une liste par partie, dans l'ordre du premier départ de lot. Pour une file seule, c'est l'ordre de la Constellation.
- **Fusion par cut** : le dernier lot qui a eu le cut pour cible décide. S'il ne le signale pas, le cut n'est plus proposé.
- **Champs** : chaque entrée porte son `batchId`, chaque liste porte `batchIds`.
- **Service worker** : `correctionListe` passe par la couverture quand aucun `batchIds` n'est demandé. Avec `batchIds`, le comportement de CH-028 et CH-035 est inchangé.
- **Journal** :
  - `correction-liste` : une par lot, même format ;
  - `correction-couverture` (nouveau) : parties, lots, exclus, retirés, entrées avant et après fusion ;
  - `correction-debut` et la séance Écho : tous les lots.
- **Tout repris** : si tous les lots ont déjà été repris, le refus est dit clairement et la fin précédente reste affichée.
- **Signal** (lecture de la vue ; habillage de CH-036) : « Parties 0, 1 · 3 lots » ; « 2 lots » sur la ligne d'une partie qui en porte plusieurs.
- **Panneau** : `panel.js` lit `batchIds` pour ne pas redemander la liste d'un lot déjà couvert.
- **Outil** : `tools/aurore-parties.cjs couverture <dossier>`.
