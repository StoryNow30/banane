# CH-014 : rapport

**Livré** sur `chantier/CH-014`, dans `maquettes/ui-v2/` : 34 maquettes HTML jouables du panneau, en sept familles de conception ; `index.html` qui les compare (scène, thème, largeur, mouvement communs) ; `RECHERCHE.md` ; 67 fiches dans `recherche/` (une par référence, une par maquette). Rien dans `src/`, aucun manifeste, aucune version.

**Demandes de l'opérateur en cours de route** (dans la conversation de la session fille) : consulter aussi cinq dépôts GitHub (ThinkingOrbs, SwiftPieces, KoiPond, Scrubbers, Libraries.dev) ; « un maximum de propositions », puis « au minimum 30 » ; lecture « parfaitement approfondie, notamment le code », en prenant le temps ; motion design pensé partout ; Figma autorisé si utile (non utilisé : les maquettes doivent être jouables). Il a jugé la première série (6 maquettes partant de métaphores du métier) décevante : elle a été abandonnée avant toute poussée. ÉTABLI : l'interface actuelle, l'historique git et les anciennes maquettes n'ont jamais été ouverts.

**Méthode.** Moteur de démo commun (même sens dans toutes les maquettes : Lancer = lot neuf, Continuer = même lot, Préparer = ne lance rien), sept familles (feuille blanche, instruments, mouvement, motifs d'app, éditorial, lumière, signalétique), six concepteurs en parallèle sans accès aux maquettes des autres, chacun ayant d'abord étudié ses références à fond (dépôts lus jusqu'au code). Skill de raffinement appliquée par captures et autocritique (la notation « council » à deux auditeurs n'a pas pu être lancée). Avertissement de l'intégrateur appliqué : aucune métaphore de voie, rail ou nuage de points.

**Mesuré (ÉTABLI, `sources/verifier.cjs`, Chromium)** : sur les 34 maquettes × 20 scènes × clair/sombre × 360/420/600 px, 0 erreur de console, 0 débordement horizontal, contraste minimal du texte entre 4,68:1 et 6,73:1. Chaque maquette jouée aussi en mouvement actif sans erreur. Scan d'identité vert ; `tests/scan-identite.test.cjs` 11/11.

**Accès refusés, non contournés** : land-book (HTTP 403, défi Cloudflare) ; pièces d'inspora, designspells, siteinspire (HTTP 429, « Vercel Security Checkpoint ») ; janina.works (HTTP 403) ; parcours mobbin et code v0 derrière un compte ; pages « image » et « studio » de libraries.dev (délai dépassé) ; paquet npm Radix refusé par les permissions de la session.

**Limites.** Le contraste est mesuré sur les fonds CSS, pas sur les canvas ni les dégradés. Le mouvement actif a été joué et regardé, pas mesuré. Le moteur recrée le panneau toutes les 0,9 s ; chaque famille a protégé ses animations, mais une implantation devra rendre par différences. Dans `app-ilot`, les commandes de marche sont dans l'îlot (un toucher pour les ouvrir), choix de conception à confirmer. Données fictives.

**Pour l'opérateur.** Ouvrir `maquettes/ui-v2/index.html`, régler la scène (« En cours », « Fin de lot », « Ce qui reste »…), filtrer par famille ; chaque titre ouvre la maquette seule avec sa régie et ses notes. Les pistes à approfondir après son choix : fusionner deux logiques proches (par exemple un instrument et une signalétique), puis passer au rendu par différences.
