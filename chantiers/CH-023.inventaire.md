## Commandes et mesures

Le contrôle de conservation compare le répertoire des scènes et des commandes de `Q-signal.html` et `S-file-de-parties.html` avec les deux pages livrées. Aucun manque ; trois scènes et trois commandes supplémentaires rendent l’arrêt, la relecture active et la pause Écho jouables. Le passage de cut reste la simulation explicitement fictive de la référence.

Matrice : 36 surfaces × 8 largeurs × 2 thèmes par page. Balayage : 32 surfaces × 241 largeurs entières × 2 thèmes par page. Les quatre causes d’alerte de file sont dans la matrice ; la cause « page inchangée » représente cette scène dans le balayage. Mouvement réduit : zéro animation active, puis contrôle système séparé sans option manuelle. **88 groupes de parcours**, huit combinaisons page × taille × thème ; les libellés de chaque groupe sont dans le JSON.

Limites : contraste calculé sur fonds pleins, pas un audit complet d’accessibilité ; aucune mesure terrain ni comparaison esthétique indépendante.

Le JSON est comprimé sans perte ; pour le lire : `gzip -dc chantiers/CH-023.mesures.json.gz`.
