# CH-067 — Audit et essais rouges des correctifs de vitesse du tronc (06/11/2026)

Exécutant : Codex (ChatGPT), sur ordre de l'opérateur. Branche `chantier/CH-067`, partie de `claude/50-test17`. Lis d'abord `CLAUDE.md` et `fiches/PASSATION_SESSION.md`, puis `CHANGELOG.md`, section « Tronc 5.0 — 06/11 ».

## But
Quatre correctifs de vitesse sont dans le tronc et dans le paquet que l'opérateur utilise sur le terrain :
- CH-058 : index en mémoire du journal (`src/journal-index.js`) ;
- CH-059 : état sauvegardé par morceaux (`src/etat-morceaux.js`, `src/storage.js`, `save()` de `src/engine.js`) ;
- CH-060 : relecture quand le signal d'ESV s'éteint (`src/relecture-signal.js`, son branchement dans `background.js`) ;
- CH-062 : signal de fin de chargement corrigé des requêtes échouées (`chargementsEffectifs`, `repliLigneBase`, `trouEchec` dans `src/adapter-page.js` et `src/esv-observer.js`).

Un défaut dans ces correctifs ferait perdre l'état à la reprise d'un lot, rater une écriture du journal, ou attendre trop peu les points d'ESV. Il faut les trouver AVANT le terrain.

## Ce qu'il faut faire
1. Lis ces fichiers et leurs essais (`tests/*journal*`, `tests/*etat*`, `tests/*relecture-signal*`, `tests/lot-signal-ligne-de-base.test.cjs`, `tests/deplacement-vue-journal*.test.cjs`).
2. Cherche en priorité :
   - un index du journal qui diverge d'IndexedDB : écriture concurrente, redémarrage du service worker, vidage, export ;
   - des morceaux d'état perdus, mélangés ou relus d'une ancienne version : écriture interrompue, quota plein, retour vers un ancien paquet ;
   - un compteur de chargement qui descend sous zéro ou reste bloqué : requête annulée, réessai, nœud chargé deux fois ;
   - toute situation où Ariane validerait ou poserait sans que les points soient chargés.
3. Pour chaque défaut réel : un essai `tests/ch067-*.test.cjs` qui échoue sur le tronc (sous 20 s), avec un scénario concret. Ne corrige rien dans `src/` : l'intégrateur décide. Joins un `.patch` proposé dans `chantiers/CH-067/`.
