# CH-001 : scan des motifs interdits et outil de contrôle

**Exécutant :** Cursor (modèle de Cursor), sur le poste de l'opérateur. **Branche :** `chantier/CH-001` partie de `claude/50-test17`. **Coût prévu :** une heure, un seul passage.

## But
Avant d'ouvrir le dépôt à un exécutant externe, s'assurer qu'aucun fichier **suivi par git** ne contient : nom d'opérateur, adresse d'ESV (hôte ou URL), code de projet ESV, UUID, courriel. Et laisser un outil qui le vérifie à chaque `verify`.

## Ce qui est livré
1. `tools/scan-identite.cjs` : parcourt `git ls-files` (jamais `node_modules`, jamais les zips), cherche :
   - courriel : `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}` ;
   - adresse web : `https?://[^\s"'<>)]+`, **sauf** une liste blanche en tête du fichier (w3.org, schémas JSON, licences de polices `scripts.sil.org`, dépôts github des polices, docs Chrome `developer.chrome.com`, `code.claude.com`) ;
   - code de projet ESV : `Project__\d{6}` et `[Pp]rojet[_ ]?\d{6}_\d{6}` ;
   - UUID : `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}` ;
   - **motifs confidentiels** (nom de l'opérateur, hôte d'ESV) : lus dans la variable d'environnement `ARIANE_MOTIFS_INTERDITS` (expressions régulières séparées par `|`), fournie par l'opérateur au lancement ; **jamais écrits dans le dépôt**. Sans la variable, l'outil le dit et ne contrôle que les quatre motifs publics.
   Sortie : une ligne par occurrence `chemin:ligne:motif`, code de retour 1 s'il y a au moins une occurrence.
2. `tests/scan-identite.test.cjs` : lance l'outil sur l'arbre ; vert quand zéro occurrence. Ajouté au verify par sa seule présence dans `tests/`.
3. Les corrections : chaque occurrence trouvée est remplacée par « l'opérateur », « l'hôte ESV », « identifiant du lot », ou lue depuis une variable d'environnement si un script en a besoin pour fonctionner. **Exception documentée** : `audit/verification.txt` est un fichier généré par le verify ; si des titres d'essais y portent encore un nom, corriger **le titre dans le fichier d'essai**, et le relevé sera régénéré par l'intégrateur.
4. `chantiers/CH-001.rapport.md` : nombre d'occurrences par motif avant correction, liste des fichiers corrigés, ce qui reste et pourquoi (une demi-page).

## Interdits
- Ne pas toucher `src/engine.js`, `src/adapter-page.js`, `src/geometry*.js`, `src/gcv2*.js`, `src/lot-decision.js`, `background.js` (sauf une chaîne de texte strictement identique en comportement), `manifest.json`, la version, `CHANGELOG.md`, `DECISIONS.md`.
- Ne pas réécrire l'historique git ; ne pas pousser sur `claude/50-test17`.
- Ne jamais écrire dans un fichier la valeur d'un motif confidentiel, même en commentaire ou dans un essai.

## Critère de fin
`ARIANE_MOTIFS_INTERDITS='…' node tools/scan-identite.cjs` rend 0 sur la branche ; `node --test tests/scan-identite.test.cjs` vert ; rapport écrit ; branche poussée.
