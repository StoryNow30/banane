## Ce qui change
- **`src/ui5.js`** : l'instantané lit la carte `#file-parties` du panneau d'avant (`fileDuPanneau`) : état de la vue `fileParties`, « préparée », nombre choisi, phrases, alerte, bilan et libellés écrits par `afficherFile`. Lecture seule. Nouvelles actions propres : `sg:file` (ouvre la boîte) et `sg:file-n:<n>` (clic sur le bouton de `#file-n` de ce nombre). La boîte se referme dès que la file n'est plus au repos. Aucun message nouveau au service worker.
- **`src/signal-rendu.js`** (`fileModele`, `fileHtml`, `boiteFileHtml`), d'après la variante A (D-261) et le style de l'interface actuelle (D-271) :
  - **au repos**, dans l'écran « Prêt » seulement : un bouton secondaire « File de parties · prête » qui ouvre la boîte ;
  - **la boîte** : nombre de parties (1, 2, 3, 4, 5, 8), puis « Préparer la file » (ne lance rien), puis « Lancer la file · n parties » (referme la boîte) ;
  - **préparée** : « Lancer la file » devient l'action pleine, « Démarrer le lot » passe à côté ;
  - **pendant la file** (lot, deuxième passe, relecture, changement) : un bandeau « File de parties · partie k sur n », la phase et « Arrêter la file » (`#file-secondaire`). « Démarrer le lot » et « Nouveau lot » sont retirés. Le changement de partie verrouille l'écran ;
  - **arrêtée ou finie, lot clos** : l'écran de la file, avec l'alerte, le bilan par partie, « Préparer la reprise » ou « Fermer le bilan », et l'export en bouton, jamais automatique. Si le lot est encore ouvert ou en alerte, il garde l'écran et la file passe dans le bandeau.
  - **palette** : « File de parties » au repos, « Arrêter la file » pendant la file (seconde Entrée, comme les autres commandes dangereuses).
- **`panel-signal.css`** : le style du bandeau, du bilan et de la boîte (jetons de Signal). Correctif au passage : entre 480 et environ 520 px de large, la barre débordait de 11 px (le bouton Réglages sortait), **sans la file**. ÉTABLI par mesure ; la puce se rétrécit maintenant.
- **Figma** (fichier `ZrK16dO2MGOQp9lufe7lwF`, nouvelle page « CH-025 · File de parties », aucune page existante touchée) : 9 états × (600 × 760, 360 × 480) × (sombre, clair), soit 36 fenêtres.
