Non retenu : le format du journal est lu par de nombreux outils (jointure, Aurore, analyses), pour un gain ≤ 1 % du lot.
- Le journal (23,2 Mo) et le bilan (21,7 Mo) dépassent seuls les 17 Mo d'un volume : un fichier JSON n'est jamais coupé (volume à lui seul).
